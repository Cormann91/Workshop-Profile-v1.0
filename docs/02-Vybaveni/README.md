# 02 – Vybavení

> **Workshop Profile v1.0 — 02 Vybavení**
>
> Evidence skutečně vlastněného vybavení vývojové dílny.
> Technické údaje jsou uváděny pouze tam, kde byly potvrzeny ve zdrojovém inventáři nebo následně potvrzeny uživatelem.

## Účel
Tato část Workshop Profile eviduje fyzické vybavení dílny: měřicí techniku, elektronickou laboratoř, kompresorovou a svařovací techniku, elektrické a ruční nářadí, dílenské vybavení, stroje a výpočetní techniku se softwarem.

## Zásady evidence
- Eviduje se skutečně vlastněné nebo potvrzeně dostupné vybavení dílny.
- Položky se nezařazují duplicitně.
- Materiálové zásoby nejsou vydávány za vybavení.
- Technologie dostupné prostřednictvím zaměstnání patří do 03 – Technologické možnosti.
- Neznámé údaje se nedoplňují odhadem.
- Stav typu „v renovaci“, „plánovaný odprodej“ nebo „chybí HW klíč“ se zachovává, pokud je relevantní pro využitelnost.
