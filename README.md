# Workshop Profile

## Účel

**Workshop Profile** je informační databáze vývojové dílny.

Jejím účelem je soustředit na jednom místě přehled prostředí, vybavení a technologických možností dílny a poskytovat praktický informační základ při realizaci budoucích projektů a při řešení technologických a konstrukčních výzev.

Dokumentace je určena především pro dlouhodobé používání a průběžnou aktualizaci podle skutečného stavu dílny.

## Struktura

| Pilíř | Název | Obsah |
|---|---|---|
| 01 | [Dílna](docs/01-Dilna/README.md) | Prostory a technická infrastruktura dílny |
| 02 | [Vybavení](docs/02-Vybaveni/README.md) | Vlastní vybavení, nářadí, stroje, výpočetní technika a software |
| 03 | [Technologické možnosti](docs/03-Technologicke-moznosti/README.md) | Technologie dostupné prostřednictvím zaměstnání a externích kooperací |

## Zásady dokumentace

- Dokumentace vychází ze skutečného stavu dílny a dostupných zdrojových údajů.
- Neznámé nebo nepotvrzené údaje se nedoplňují odhadem.
- Vlastní vybavení je odděleno od technologií dostupných prostřednictvím zaměstnání nebo kooperací.
- Dokumentace má zůstat praktická a přehledná; nevytvářejí se části s minimální informační hodnotou.
- Změny se provádějí přímo v příslušných Markdown dokumentech.
- Centrální historie změn je vedena v [CHANGELOG.md](CHANGELOG.md).

## Použití

Hlavní `README.md` slouží jako vstupní stránka celého Workshop Profile.

Jednotlivé části mají vlastní `README.md`, který slouží jako jejich lokální navigace. Dokumenty mezi sebou používají relativní odkazy, aby fungovaly přímo v GitHub repozitáři.
